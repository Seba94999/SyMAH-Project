# Route Handler Skill

## Objetivo

Gestionar las rutas del sistema frontend.

## Entradas

- Nombre de la ruta.
- Componentes asociados.

## Salidas

- Archivo de la ruta creado.
- Configuración de la ruta.

## Restricciones

- No incluir lógica de negocio.
- Mantener la modularidad.

## Ejemplos

- "Crea una ruta para el dashboard."
- "Genera una ruta para la página de clientes."
