# Create Table Skill

## Objetivo

Crear una tabla interactiva para mostrar datos.

## Entradas

- Nombre de la tabla.
- Columnas y datos requeridos.

## Salidas

- Archivo de la tabla creado.
- Código base de la tabla.

## Restricciones

- No incluir lógica de negocio.
- Mantener la accesibilidad.

## Ejemplos

- "Crea una tabla para listar clientes."
- "Genera una tabla para mostrar transacciones."
