# Create Modal Skill

## Objetivo

Crear un modal reutilizable para la UI.

## Entradas

- Nombre del modal.
- Contenido y diseño requeridos.

## Salidas

- Archivo del modal creado.
- Código base del modal.

## Restricciones

- No incluir lógica de negocio.
- Mantener la consistencia visual.

## Ejemplos

- "Crea un modal para confirmar acciones."
- "Genera un modal para mostrar detalles de un cliente."
