# Create Chart Skill

## Objetivo

Crear un gráfico interactivo para visualizar datos.

## Entradas

- Tipo de gráfico.
- Datos requeridos.

## Salidas

- Archivo del gráfico creado.
- Código base del gráfico.

## Restricciones

- No incluir lógica de negocio.
- Mantener la consistencia visual.

## Ejemplos

- "Crea un gráfico de barras para métricas."
- "Genera un gráfico circular para estadísticas."
