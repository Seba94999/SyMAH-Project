# Create Component Skill

## Objetivo

Crear un nuevo componente reutilizable para la UI.

## Entradas

- Nombre del componente.
- Propiedades requeridas.

## Salidas

- Archivo del componente creado.
- Código base del componente.

## Restricciones

- No incluir lógica de negocio.
- Mantener la consistencia visual.

## Ejemplos

- "Crea un componente de tabla."
- "Genera un componente de formulario."
