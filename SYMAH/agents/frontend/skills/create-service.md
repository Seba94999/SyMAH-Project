# Create Service Skill

## Objetivo

Crear un servicio para manejar la comunicación con el backend.

## Entradas

- Nombre del servicio.
- Endpoints requeridos.

## Salidas

- Archivo del servicio creado.
- Código base del servicio.

## Restricciones

- No incluir lógica de negocio.
- Mantener la modularidad.

## Ejemplos

- "Crea un servicio para gestionar clientes."
- "Genera un servicio para transacciones."
