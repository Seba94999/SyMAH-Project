# Create Page Skill

## Objetivo

Crear una nueva página en el sistema frontend.

## Entradas

- Nombre de la página.
- Estructura y diseño requeridos.

## Salidas

- Archivo de la página creado.
- Código base de la página.

## Restricciones

- No incluir lógica de negocio.
- Mantener la modularidad.

## Ejemplos

- "Crea una página para el dashboard."
- "Genera una página para la gestión de clientes."
