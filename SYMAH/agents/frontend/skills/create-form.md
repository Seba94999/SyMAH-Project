# Create Form Skill

## Objetivo

Crear un formulario interactivo para la UI.

## Entradas

- Nombre del formulario.
- Campos requeridos.

## Salidas

- Archivo del formulario creado.
- Código base del formulario.

## Restricciones

- No incluir lógica de negocio.
- Mantener la accesibilidad.

## Ejemplos

- "Crea un formulario para registrar clientes."
- "Genera un formulario para presupuestos."
