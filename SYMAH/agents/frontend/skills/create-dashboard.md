# Create Dashboard Skill

## Objetivo

Crear un dashboard con widgets y gráficos.

## Entradas

- Nombre del dashboard.
- Widgets y gráficos requeridos.

## Salidas

- Archivo del dashboard creado.
- Código base del dashboard.

## Restricciones

- No incluir lógica de negocio.
- Mantener la modularidad.

## Ejemplos

- "Crea un dashboard para métricas financieras."
- "Genera un dashboard para la gestión de empleados."
