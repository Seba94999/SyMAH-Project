# Create Repository Skill

## Objetivo

Crear un repositorio para manejar la persistencia de datos.

## Entradas

- Nombre del repositorio.
- Modelo asociado.

## Salidas

- Archivo del repositorio creado.
- Código base del repositorio.

## Restricciones

- No incluir lógica de negocio.
- Mantener la integridad de datos.

## Ejemplos

- "Crea un repositorio para usuarios."
- "Genera un repositorio para pedidos."
