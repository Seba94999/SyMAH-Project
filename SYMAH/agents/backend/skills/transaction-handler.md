# Transaction Handler Skill

## Objetivo

Gestionar transacciones en el backend.

## Entradas

- Operaciones requeridas.
- Contexto de la transacción.

## Salidas

- Código base para manejar transacciones.

## Restricciones

- Mantener la atomicidad.
- Garantizar la consistencia.

## Ejemplos

- "Crea un manejador de transacciones para pedidos."
- "Genera un manejador de transacciones para pagos."
