# Validations Skill

## Objetivo

Validar datos de entrada en el backend.

## Entradas

- Datos a validar.
- Reglas de validación.

## Salidas

- Resultado de la validación.

## Restricciones

- No incluir lógica de negocio.
- Mantener la consistencia de datos.

## Ejemplos

- "Valida los datos de un formulario de registro."
- "Genera validaciones para entradas de API."
