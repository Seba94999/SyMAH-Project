# Create Service Skill

## Objetivo

Crear un servicio backend para lógica de aplicación.

## Entradas

- Nombre del servicio.
- Funcionalidad requerida.

## Salidas

- Archivo del servicio creado.
- Código base del servicio.

## Restricciones

- No incluir lógica de negocio crítica.
- Mantener la reutilización.

## Ejemplos

- "Crea un servicio para autenticación."
- "Genera un servicio para notificaciones."
