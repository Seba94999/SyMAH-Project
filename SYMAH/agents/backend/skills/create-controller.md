# Create Controller Skill

## Objetivo

Crear un controlador para manejar solicitudes HTTP.

## Entradas

- Nombre del controlador.
- Endpoints requeridos.

## Salidas

- Archivo del controlador creado.
- Código base del controlador.

## Restricciones

- No incluir lógica de negocio.
- Mantener la separación de responsabilidades.

## Ejemplos

- "Crea un controlador para usuarios."
- "Genera un controlador para productos."
