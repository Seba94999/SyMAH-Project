# Create Schema Skill

## Objetivo

Crear un esquema de base de datos.

## Entradas

- Nombre del esquema.
- Campos requeridos.

## Salidas

- Archivo del esquema creado.
- Código base del esquema.

## Restricciones

- No incluir lógica de negocio.
- Mantener la consistencia de datos.

## Ejemplos

- "Crea un esquema para usuarios."
- "Genera un esquema para transacciones."
