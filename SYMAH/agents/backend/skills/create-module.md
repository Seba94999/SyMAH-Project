# Create Module Skill

## Objetivo

Crear un módulo backend reutilizable.

## Entradas

- Nombre del módulo.
- Dependencias requeridas.

## Salidas

- Archivo del módulo creado.
- Código base del módulo.

## Restricciones

- No incluir lógica de negocio.
- Mantener la modularidad.

## Ejemplos

- "Crea un módulo para gestionar usuarios."
- "Genera un módulo para reportes."
