# Audit Handler Skill

## Objetivo

Registrar y auditar eventos en el sistema.

## Entradas

- Evento a auditar.
- Contexto del evento.

## Salidas

- Registro de auditoría generado.

## Restricciones

- No incluir lógica de negocio.
- Mantener la trazabilidad.

## Ejemplos

- "Crea un manejador de auditoría para accesos."
- "Genera un manejador de auditoría para cambios en datos."
